## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Game Library** | Organize Xbox titles with cover art and current xemu compatibility |
| **Config Profiles** | Save graphics and compatibility settings per game title |
| **HDD Manager** | Browse and manage xemu hard disk image contents |
| **Quick Launch** | Launch any game with its saved profile directly from the manager |
